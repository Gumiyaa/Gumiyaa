## Halo 👋

Aku **Gumi**, seorang web developer dari Indonesia yang juga senang mengurus tampilan.
Buatku, kode dan desain itu satu paket — aplikasi yang bagus bukan cuma yang fiturnya jalan,
tapi yang juga enak dipakai dan tidak bikin bingung.

Aku paling sering menulis **JavaScript/TypeScript, PHP, dan SQL**. Di sisi frontend aku nyaman
dengan **React** dan **Vue**, di backend aku biasa menulis REST API sendiri — kadang pakai
framework, kadang murni native. Selain web, aku juga main-main dengan **Unity** dan **Blender**
karena game adalah alasan pertama aku belajar ngoding.

> Semua proyek di bawah aku tulis sendiri, sambil belajar, dan sambil bolak-balik buka dokumentasi.

## Yang lagi aku bangun

### 🩺 Carewell — Clinic Management

Aplikasi manajemen klinik full-stack: pasien, jadwal dokter, rekam medis, billing, laporan, dan
jejak aktivitas. Hak akses tiga peran (admin / dokter / resepsionis) ditegakkan **dua lapis** —
backend menolak `403`, frontend menyembunyikan menu. Dokter cuma bisa melihat pasien yang pernah
ia tangani, walaupun ID-nya ditebak langsung.

`Vue 3` · `Express 5` · `MySQL 8` · `JWT` · `bcrypt`

[![Source](https://img.shields.io/badge/Source-carewell--clinic--management-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Gumiyaa/carewell-clinic-management)

### 👥 SDM Pro HRIS

HRIS full-stack untuk karyawan, departemen, jabatan, absensi, dan cuti — plus dashboard
analitik yang semua angkanya dihitung langsung dari database, dan export laporan ke XLSX.
Ada unit test + integration test API yang jalan otomatis di GitHub Actions, pakai database
sementara supaya tidak menyentuh data asli.

`React 19` · `Vite` · `Tailwind v4` · `PHP 8` · `SQLite`

[![Source](https://img.shields.io/badge/Source-rdbms-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Gumiyaa/rdbms)
[![CI](https://github.com/Gumiyaa/rdbms/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/Gumiyaa/rdbms/actions/workflows/ci.yml)

### 🧠 KPLab — Kraepelin & Pauli Test

Web latihan psikotes yang lahir dari kebingungan sendiri: bikin latihan Kraepelin & Pauli yang
rapi, ada timer, streak counter, dan preferensi kustom (efek suara, arah soal). Dari yang tadinya
trauma lihat deretan angka, sekarang latihannya seru kayak main game.

`HTML` · `CSS` · `JavaScript`

[![Live](https://img.shields.io/badge/Live-KPLab-556C4E?style=flat-square&logo=githubpages&logoColor=white)](https://gumiyaa.github.io/KPLab)
[![Source](https://img.shields.io/badge/Source-KPLab-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Gumiyaa/KPLab)

### 🌾 Farm Farmily

Landing page pertanian keluarga — "Hasil Bumi Terbaik". Proyek kecil buat latihan layout,
tipografi, dan animasi scroll tanpa framework apa pun.

`HTML` · `CSS`

[![Live](https://img.shields.io/badge/Live-farm--farmily-556C4E?style=flat-square&logo=githubpages&logoColor=white)](https://gumiyaa.github.io/farm-farmily/)
